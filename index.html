Working with AI

AI is part of how I work every day, but it works the way I do. I use Claude Code and Cursor as coding partners and give them clear rules, reusable skills and project context, so they follow the same process I would. I make the decisions and review every change.

My workflow

  1. 01

    Understand

    A client message or ticket becomes an agreed approach and a clear definition of done, before any code is written.

  2. 02

    Plan

    Larger tasks are split into ordered build steps, so the work stays small and easy to review.

  3. 03

    Build

    Agents write code on a feature branch, run the site in a browser and check the result in light and dark mode and on mobile.

  4. 04

    Review

    Every diff gets a correctness, simplification and security review. Then I read it myself.

  5. 05

    Share

    Finished work becomes documentation the team and client can read, plus a short update for the team.

Skills I use

Skills are reusable instructions that teach the agent a specific part of my process. Each one is called on its own, when that step comes up.

/start-task

Turns a new request into an agreed approach and writes down what "done" means before we branch.

/writing-plans

Breaks an approved large task into an ordered build plan before any code is written.

/code-review

Reviews the current diff or a pull request for bugs, and can apply the fixes it finds.

/simplify

Cleans up changed code by reusing what already exists and removing what isn't needed.

/security-review

Checks the changes on a branch for security issues before they go anywhere near live.

/run

Launches the project and drives it in a browser to confirm a change actually works.

/document-feature

Writes up a shipped feature as a shared doc for QA, support or the client.

/standup-update

Writes the short Tuesday and Thursday update about what I worked on.
